# Generates a java moniker for the corresponding id.

Generates a java moniker for the corresponding id.

## Usage

``` r
.xml_moniker(id)
```

## Arguments

- id:

  Identifier of the requested information.

## Value

An internal java moniker.

## Examples

``` r
.xml_moniker("toy_id")
#> Error in .jfield("jdplus/text/base/api/XmlProvider", "S", name = "NAME"): cannot find class jdplus/text/base/api/XmlProvider
```
